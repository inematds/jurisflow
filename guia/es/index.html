Qué es

Nueve módulos, una base de datos, cero hojas de cálculo

JurisFlow es un sistema de gestión para bufetes de abogados. No es un prototipo de interfaz: tiene frontend, backend, base de datos MySQL, autenticación y un asistente de IA conectado a un LLM.

📊 Panel que cuadra las cuentas

Clientes, procesos activos, plazos del período, audiencias, ingresos, gastos y saldo — calculados a partir de los registros reales, no ingresados a mano.

⚖️ Proceso con el expediente completo

Número CNJ, tribunal, juzgado, jurisdicción, área, fase, posición del cliente, contraparte, valor de la demanda e historial de movimientos.

🤖 IA dentro del flujo

Borrador de escrito, análisis de jurisprudencia, cálculo de plazos, resumen del estado del proceso, notificación extrajudicial y contrato de honorarios.

Cómo funciona

Del primer contacto al pago de honorarios

El recorrido que sigue un caso dentro del sistema: cada etapa es un módulo y todos comparten el mismo cliente y el mismo proceso.

Atención→ Cliente→ Proceso→ Estados→ Plazos y audiencias→ Tareas→ Documentos→ Finanzas

Fases del proceso

Cada proceso sigue una secuencia fija, y el panel muestra cuántos están en cada etapa.

Inicial→ Instrucción→ Decisión→ Recurso→ Ejecución→ Archivado

Situación del caso

Independientemente de la fase, el proceso tiene un estado de cierre, que se usa en los filtros y los indicadores.

ActivoSuspendidoEn acuerdo GananciaPerdidoArchivado

🗄️ Modelo de datos

Nueve tablas: users, clients, consultations, lawsuits, lawsuit_movements, calendar_events, tasks, financial_transactions, legal_documents.

🔗 Todo conectado

Un documento apunta al cliente + proceso + abogado. Un movimiento financiero apunta al proceso que lo generó. Nada queda suelto.

🎨 Claro y oscuro

Interfaz adaptable con tema claro/oscuro, construida con React 19, Radix UI y Tailwind.

Requisitos previos

Qué debe estar en línea antes

JurisFlow es una aplicación full-stack: ejecuta un servidor Node y necesita un MySQL. No es un sitio estático.

Node.js 20+ y pnpm

El proyecto usa pnpm (hay un pnpm-lock.yaml versionado) y módulos ESM.

# comprueba las versiones
node -v
pnpm -v

MySQL accesible

La base de datos vacía ya sirve: las migraciones de Drizzle crean las nueve tablas.

# crea la base de datos
mysql -u root -p -e "CREATE DATABASE jurisflow"

Clave de un LLM

Solo para el Asistente Jurídico. Los otros ocho módulos funcionan sin ella.

# ve a .env
BUILT_IN_FORGE_API_URL=
BUILT_IN_FORGE_API_KEY=
Guía de uso · paso a paso

Del clon al sistema en funcionamiento

Cinco pasos. Al final tendrás JurisFlow en el navegador, ya cargado con datos de demostración.

1

Clona el repositorio

Todo el código —frontend, backend, migrations y pruebas— está en un solo repo.

git clone https://github.com/inematds/jurisflow.git
cd jurisflow
2

Instala las dependencias

Usa pnpm: el lockfile es suyo y hay un patch aplicado en wouter que npm ignora.

pnpm install  # instala front + back de una sola vez
3

Configura el entorno

Copia el ejemplo y complétalo. DATABASE_URL e JWT_SECRET son obligatorios; las claves del LLM solo si vas a usar el asistente.

cp .env.example .env

# .env — lo mínimo para poner en marcha
DATABASE_URL=mysql://usuario:senha@localhost:3306/jurisflow
JWT_SECRET=um-segredo-aleatorio-e-longo
PORT=3000
4

Crea las tablas

Drizzle genera las migrations a partir del schema y las aplica en la base de datos. Es el mismo comando en ambas etapas.

pnpm db:push  # drizzle-kit generate && drizzle-kit migrate
5

Inicia el servidor

Un solo proceso sirve a la API y al frontend. Abre la dirección, inicia sesión y haz clic en “Generar datos de ejemplo” en el menú para cargar clientes, procesos, audiencias, tareas, finanzas y documentos.

pnpm dev  # http://localhost:3000

Otros comandos

pnpm build — compila front y back
pnpm start — ejecuta la build de producción

Calidad

pnpm check — verificación de tipos de TypeScript
pnpm test — suite de Vitest

Formato

pnpm format — Prettier en todo, con las reglas del repo.

Demo comercial

Base de datos vacía + “Generar datos de ejemplo” = despacho ficticio listo para presentar en minutos.

Asistente Jurídico de IA

Seis operaciones, todas en Derecho brasileño

El asistente está configurado para trabajar con CPC, CPP, CLT, Constitución Federal, Código Civil, CDC y la jurisprudencia del STF, STJ y TST. Tú eliges la operación y describes el caso en texto corrido en portugués.

📝 Borrador de escrito judicial

Se describe el caso; devuelve la estructura del escrito con fundamentos y peticiones.

🔍 Análisis de jurisprudencia

Investiga el criterio de los tribunales sobre el tema y cómo se aplica al caso.

📅 Cálculo de plazos

Cómputo a partir de la notificación, considerando la regla procesal aplicable.

📄 Resumen del avance

Traduce el despacho o el movimiento procesal a un lenguaje claro para el cliente.

📬 Notificación extrajudicial

Redacta la notificación a partir del hecho y la pretensión informados.

🤝 Contrato de honorarios

Prepara el contrato con el objeto, la forma de cobro y las cláusulas habituales.

⚠️ Verifica todas las citas antes de usarlas.

El asistente todavía no está conectado a una base jurídica de verificación. Se le instruye para citar artículos de ley y jurisprudencia, pero un LLM por sí solo puede producir referencias incorrectas. Trata el resultado como un borrador: toda ley y todo precedente citado deben verificarse en la fuente antes de incorporarse al expediente.

Roadmap

Dónde está y adónde va

JurisFlow es hoy un MVP funcional de ERP/CRM jurídico con asistente de IA. Lo que sigue es la integración con el mundo exterior y, a futuro, delegar el trabajo repetitivo a agentes.

Hoy
ERP/CRM jurídico + asistente de IANueve módulos funcionando sobre MySQL, autenticación OAuth + JWT, modo de demostración con un clic y el asistente cubriendo seis operaciones.
Siguiente
Fuentes verificadas y documentos listosInvestigación + citas + validación de fuentes jurídicas en el asistente; generación directa de DOCX/PDF de los escritos; RAG sobre los documentos del propio despacho.
Integraciones
El sistema hablando con el exteriorCaptura automática de movimientos del CNJ, publicaciones del Diario Oficial, WhatsApp, Gmail, Google Calendar, OCR de documentos, firma digital y cobros por PIX/boleto.
Escala
Operación de un despacho grandePermisos avanzados por equipo, auditoría detallada, varias empresas y oficinas, y automatización de los plazos procesales.
Horizonte
JurisFlow AgenticDejar de ser solo un software para despachos y convertirse en su sistema operativo: agentes de clasificación, área jurídica, procesos, plazos, documentos y finanzas trabajando en cadena — con el abogado como supervisor que aprueba.
