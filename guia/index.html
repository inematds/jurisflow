O que é

Nove módulos, um banco de dados, zero planilha

O JurisFlow é um sistema de gestão para escritório de advocacia. Não é um protótipo de interface: tem frontend, backend, banco MySQL, autenticação e um assistente de IA ligado a um LLM.

📊 Painel que fecha a conta

Clientes, processos ativos, prazos do período, audiências, receitas, despesas e saldo — calculados a partir dos lançamentos reais, não digitados à mão.

⚖️ Processo com a ficha completa

Número CNJ, tribunal, vara, comarca, área, fase, posição do cliente, parte contrária, valor da causa e o histórico de movimentações.

🤖 IA dentro do fluxo

Minuta de petição, análise de jurisprudência, cálculo de prazo, resumo de andamento, notificação extrajudicial e contrato de honorários.

Como funciona

Do primeiro contato ao honorário pago

O caminho que um caso percorre dentro do sistema — cada etapa é um módulo, e todos compartilham o mesmo cliente e o mesmo processo.

Atendimento→ Cliente→ Processo→ Andamentos→ Prazos & Audiências→ Tarefas→ Documentos→ Financeiro

Fases do processo

Cada processo caminha por uma sequência fixa, e o painel mostra quantos estão em cada ponto.

Inicial→ Instrução→ Decisão→ Recurso→ Execução→ Arquivado

Situação do caso

Independente da fase, o processo carrega um status de desfecho — usado nos filtros e nos indicadores.

Pré-requisitos

O que precisa estar no ar antes

O JurisFlow é uma aplicação full-stack: roda um servidor Node e precisa de um MySQL. Não é um site estático.

Node.js 20+ e pnpm

O projeto usa pnpm (há um pnpm-lock.yaml versionado) e módulos ESM.

# confira as versões
node -v
pnpm -v

MySQL acessível

Banco vazio já serve — as migrations do Drizzle criam as nove tabelas.

# crie o banco
mysql -u root -p -e "CREATE DATABASE jurisflow"

Chave de um LLM

Só para o Assistente Jurídico. Os outros oito módulos funcionam sem ela.

# vai no .env
BUILT_IN_FORGE_API_URL=
BUILT_IN_FORGE_API_KEY=
Guia de uso · passo a passo

Do clone ao sistema rodando

Cinco passos. Ao final você tem o JurisFlow no navegador, já populado com dados de demonstração.

1

Clone o repositório

O código inteiro — frontend, backend, migrations e testes — vive num repo só.

git clone https://github.com/inematds/jurisflow.git
cd jurisflow
2

Instale as dependências

Use pnpm: o lockfile é dele, e há um patch aplicado no wouter que o npm ignora.

pnpm install  # instala front + back de uma vez
3

Configure o ambiente

Copie o exemplo e preencha. DATABASE_URL e JWT_SECRET são obrigatórios; as chaves do LLM só se você for usar o assistente.

cp .env.example .env

# .env — o mínimo para subir
DATABASE_URL=mysql://usuario:senha@localhost:3306/jurisflow
JWT_SECRET=um-segredo-aleatorio-e-longo
PORT=3000
4

Crie as tabelas

O Drizzle gera as migrations a partir do schema e aplica no banco. É o mesmo comando nas duas etapas.

pnpm db:push  # drizzle-kit generate && drizzle-kit migrate
5

Suba o servidor

Um processo só serve a API e o frontend. Abra o endereço, faça login e clique em “Gerar Dados Exemplo” no menu para popular clientes, processos, audiências, tarefas, financeiro e documentos.

pnpm dev  # http://localhost:3000

Outros comandos

pnpm build — compila front e back
pnpm start — roda a build de produção

Qualidade

pnpm check — typecheck TypeScript
pnpm test — suíte Vitest

Formatação

pnpm format — Prettier em tudo, com as regras do repo.

Assistente Jurídico IA

Seis operações, todas em Direito Brasileiro

O assistente é instruído a trabalhar com CPC, CPP, CLT, Constituição Federal, Código Civil, CDC e a jurisprudência do STF, STJ e TST. Você escolhe a operação e descreve o caso em português corrido.

📝 Minuta de petição

Descreve-se o caso; ele devolve a estrutura da peça com fundamentação e pedidos.

🔍 Análise de jurisprudência

Levanta o entendimento dos tribunais sobre o tema e como ele se aplica ao caso.

📅 Cálculo de prazo

Contagem a partir da intimação, considerando a regra processual aplicável.

📄 Resumo de andamento

Transforma o despacho ou a movimentação em linguagem clara para o cliente.

📬 Notificação extrajudicial

Redige a notificação a partir do fato e da pretensão informados.

🤝 Contrato de honorários

Monta o contrato com objeto, forma de cobrança e cláusulas usuais.

Cliente trabalhou como analista de logística,
fazia duas horas extras diárias e foi demitido
sem receber aviso prévio.

Análise de jurisprudência — consumidor

Jurisprudência do STJ sobre dano moral
em caso bancário — Tema 1061.
⚠️ Confira toda citação antes de usar.

O assistente ainda não está ligado a uma base jurídica verificadora. Ele é instruído a citar artigos de lei e jurisprudência, mas um LLM sozinho pode produzir referência incorreta. Trate a saída como rascunho: toda lei e todo precedente citado precisa ser conferido na fonte antes de ir para os autos.

Roadmap

Onde está e para onde vai

O JurisFlow hoje é um MVP funcional de ERP/CRM jurídico com assistente de IA. O que vem depois é integração com o mundo externo — e, no horizonte, delegar o trabalho repetitivo a agentes.

Hoje
ERP/CRM jurídico + assistente de IANove módulos funcionando sobre MySQL, autenticação OAuth + JWT, modo de demonstração com um clique e o assistente cobrindo seis operações.
Próximo
Fontes verificadas e documentos prontosPesquisa + citação + validação das fontes jurídicas no assistente; geração direta de DOCX/PDF das peças; RAG sobre os documentos do próprio escritório.
Integrações
O sistema conversando com foraCaptura automática de movimentações CNJ, publicações do Diário Oficial, WhatsApp, Gmail, Google Calendar, OCR de documentos, assinatura digital e cobrança por PIX/boleto.
Escala
Operação de escritório grandePermissões avançadas por equipe, auditoria detalhada, multiempresa/multiescritório e automação dos prazos processuais.
Horizonte
JurisFlow AgenticDeixar de ser só um software para escritório e virar o sistema operacional dele: agentes de triagem, jurídico, processos, prazos, documentos e financeiro trabalhando em cadeia — com o advogado como supervisor que aprova.
